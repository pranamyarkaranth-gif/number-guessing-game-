# number-guessing-game-
A simple Java-based Number Guessing Game where the computer randomly generates a number and the player tries to guess it within limited attempts.

->Features
Random number generation
User input handling
Hints for high/low guesses
Attempt counter
Winning and losing messages
Beginner-friendly Java project
->Technologies Used
Java
Scanner Class
Random Class
->How It Works
The program generates a random number.
The user enters a guess.
The program checks whether the guess is:
Too high
Too low
Correct
The game continues until the user guesses correctly or attempts are over.
